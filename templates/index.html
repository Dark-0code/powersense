About PowerSense

Intelligent Power Analysis System

Features

  • ✓ Z-Score & Isolation Forest Anomaly Detection
  • ✓ ARIMA Time-Series Forecasting
  • ✓ Fourier Analysis for Pattern Detection
  • ✓ Markov Chain State Transitions
  • ✓ Cost Analysis & Recommendations
  • ✓ Stability Scoring
  • ✓ Full Export Capabilities
  • ✓ Session History & Comparison

Algorithms Used

This application uses advanced machine learning algorithms including:
• ARIMA (AutoRegressive Integrated Moving Average) for time-series forecasting
• Isolation Forest for robust anomaly detection
• Z-Score normalization for statistical analysis
• Fourier Transform for cyclic pattern detection
• Markov chains for state transition modeling
• Linear regression for trend analysis

Getting Started

1. Upload a power log file (CSV or TXT format)
2. Set your electricity tariff and appliance wattage
3. Click "Analyse" to run the full analysis
4. View results, forecasts, and recommendations
5. Export your findings as CSV or JSON
